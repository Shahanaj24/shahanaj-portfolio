# Shahanaj Shaikh Portfolio

A modern MERN portfolio showcasing projects, skills, education, and contact details for Shahanaj Shaikh.

## Tech Stack

- React + Vite + Tailwind CSS
- React Router
- Framer Motion
- Express.js + Mongoose
- MongoDB

## Features

- Responsive portfolio pages
- Theme toggle with persistence
- API-backed project data and contact form
- Project filtering and detail pages
- Downloadable resume
- Mobile navigation and professional landing page

## Installation

```bash
git clone <repository-url>
cd portfolio
npm install

cd client
npm install

cd ../server
npm install
```

## Environment Setup

Create `.env` files in the server folder:

```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/portfolio
CLIENT_URL=http://localhost:5173
```

## Run locally

```bash
npm run dev
```

## Deployment

- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
